# ProductsAPI

Bu proje, ASP.NET Core ile Web API geliştirmeyi öğrenmek için oluşturulmuş örnek bir çalışmadır.  
Ürün yönetimi üzerinden temel API yapısı, EF Core, Identity ve JWT gibi konular pratik şekilde uygulanmaktadır.

## 📚 Bu Projede Neler Öğreniyoruz?

- Web API Nedir?
- ApiController yapısı
- Models ve veri modelleri
- HTTP Status Codes kullanımı
- Entity Framework Core
- Veri Sorgulama (GET)
- Veri Ekleme (POST)
- Veri Güncelleme (PUT)
- Veri Silme (DELETE)
- DTO (Data Transfer Object)
- ASP.NET Identity ile kullanıcı yönetimi
- Token Based Authentication
- JWT (JSON Web Token)
- CORS ayarları
- Serialize & Deserialize işlemleri
- JavaScript Client App ile API tüketimi
- ASP.NET Client App ile API tüketimi
